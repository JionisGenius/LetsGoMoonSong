# 클론 최묘석의 농사

[제한 사항]

| 항목 | 제한 |
| --- | --- |
| 지도의 크기 | $N \times N$ |
| 진행 시간 | $M$일 |
| 지도 정보 | `0`: 농지, `1`: 산지 |
| 지도의 테두리 | 항상 산지 |

---

정사각형 모양의 지도에 농사를 지을 수 있는 농지와 지나갈 수 없는 산지가 있다.

지도에서 `0`은 농지를, `1`은 산지를 나타낸다. 지도의 테두리는 모두 산지로 주어진다.

클론 최묘석 한 명을 농지 한 칸에 배치하고, 상하좌우 네 방향 중 하나를 최초로 바라보게 한다.

클론 최묘석은 총 $M$일 동안 매일 **낮 행동**, **밤 이동**, **작물 성장**의 순서로 행동한다.

클론 최묘석의 최초 위치와 최초 방향을 적절히 정했을 때 얻을 수 있는 최대 수확량을 구하시오.

## 낮 행동

낮에는 현재 칸의 상태에 따라 다음 중 하나의 행동을 한다.

- 현재 칸에 곡식이 열려 있다면 곡식을 수확하고, 해당 칸을 빈 농지로 만든다.
- 현재 칸이 빈 농지이고 상하좌우로 이동할 수 있는 칸이 하나 이상 있다면, 현재 칸에 씨앗을 심는다.
- 위의 두 조건을 모두 만족하지 않으면 아무 행동도 하지 않는다.

한 번의 낮에 수확과 씨앗 심기를 동시에 수행하지 않는다.

## 밤 이동

밤에는 현재 바라보는 방향을 기준으로 다음 우선순위에 따라 이동할 수 있는 첫 번째 칸으로 한 칸 이동한다.

1. 오른쪽
2. 정면
3. 왼쪽
4. 뒤쪽

이동한 경우, 이동한 방향이 새로운 진행 방향이 된다.

빈 농지와 곡식이 다 자란 농지만 이동할 수 있으며, 산지와 작물이 자라고 있는 농지로는 이동할 수 없다.

네 방향 모두 이동할 수 없다면 현재 위치와 방향을 유지한다.

## 작물 성장

밤 이동이 끝나면 하루가 지나고 모든 농지의 작물이 동시에 성장한다.

낮에 심은 씨앗은 그날 밤 이동이 끝난 후 싹이 난다.

어떤 농지에서 지금까지 곡식을 $k$번 수확했다면, 해당 농지에 새로 난 싹은 이후 $3+k$일이 지나면 곡식이 열린다.

즉, 싹이 난 후 $3+k$번의 하루 종료 성장 처리를 받으면 수확할 수 있는 상태가 된다.

처음에는 모든 농지가 비어 있으며, 각 농지의 수확 횟수는 0이다.

---

[입력]

첫 번째 줄에 전체 테스트 케이스의 수 $T$가 주어진다.

각 테스트 케이스의 첫 번째 줄에 지도의 한 변의 길이 $N$과 진행 시간 $M$이 공백으로 구분되어 주어진다.

다음 $N$개의 줄에 길이가 $N$인 문자열로 지도 정보가 주어진다.

지도에는 클론 최묘석을 처음 배치할 수 있는 농지가 하나 이상 존재한다.

[출력]

각 테스트 케이스의 답을 순서대로 출력하며, 각 테스트 케이스마다 줄의 시작에 `#C`를 출력한다.

이때 $C$는 테스트 케이스의 번호이다.

같은 줄에 빈칸을 하나 두고, 클론 최묘석의 최초 위치와 최초 방향을 적절히 정했을 때 $M$일 동안 얻을 수 있는 최대 수확량을 출력한다.

---

**입력**

```text
2
5 8
11111
10001
10001
10001
11111
3 10
111
101
111
```

**출력**

```text
#1 3
#2 0
```
