# 봄버맨 1 — 큐브 탐험

## 문제

탐험가가 3차원 큐브의 시작 위치 `A`에 서 있다. 큐브에는 빈 통로와 벽이 있다. 탐험가는 상하좌우앞뒤 여섯 방향으로 이동하여 목적지 `Z`로 탈출하려고 한다.

**한 턴에 한 칸 이동할 수 있다.** 벽은 파괴할 수 없으며, 폭탄과 아이템은 없다. 탈출에 필요한 최소 턴 수를 구하라.

## 좌표와 이동 방향

큐브의 크기는 **8 × 8 × 8**이다. 좌표는 `(층, 행, 열)`로 나타내며 각 값은 1부터 8까지이다.

- 층은 아래에서 위로 1층부터 8층까지이다.
- 각 층의 행은 위에서 아래로 1행부터 8행까지이다.
- 각 행의 열은 왼쪽에서 오른쪽으로 1열부터 8열까지이다.

한 번의 이동으로 현재 칸과 면을 공유하는 칸으로만 이동할 수 있다.

| 방향 | 좌표 변화 |
| --- | --- |
| 위 | 층 +1 |
| 아래 | 층 -1 |
| 앞 | 행 -1 |
| 뒤 | 행 +1 |
| 왼쪽 | 열 -1 |
| 오른쪽 | 열 +1 |

큐브 밖으로 이동할 수 없다. 벽을 향한 이동은 선택할 수 없으며, 제자리 대기도 할 수 없다. `A`와 `Z`는 서로 다른 칸에 각각 하나씩 존재하고, 빈 통로처럼 이동할 수 있다.

## 칸의 종류

| 문자 | 의미 |
| --- | --- |
| `0` | 빈 통로 |
| `1` | 이동할 수 없는 벽 |
| `A` | 시작 위치 |
| `Z` | 목적지 |

## 입력

총 **64줄**에 큐브의 정보가 주어진다. 각 줄에는 공백 없이 8개의 문자가 주어진다.

- 1~8번째 줄: 1층의 1~8행
- 9~16번째 줄: 2층의 1~8행
- 같은 방식으로 57~64번째 줄: 8층의 1~8행

층 번호, 층 사이의 빈 줄, 이동 명령, 명령 개수는 입력하지 않는다. 탈출에 필요한 행동 순서는 프로그램이 직접 찾아야 한다.

## 출력

`A`에서 출발하여 `Z`에 처음 도착하기까지 필요한 **최소 턴 수**를 출력한다. 어떤 행동 순서로도 탈출할 수 없다면 `-1`을 출력한다.

## 제한

- 입력에는 `0`, `1`, `A`, `Z`만 등장한다.
- `A`와 `Z`는 각각 정확히 한 번 등장한다.
- 시간 제한: 1초
- 메모리 제한: 128 MB

### 설명

시작 위치는 (1, 1, 1), 목적지는 (8, 8, 8)이다. 이 미로는 8개 층에 모두 통로가 있으며, 막다른 길과 층 사이 연결 통로가 여러 곳에 있다. 목적지와 좌표상 가까워져도 벽 때문에 돌아가야 한다.

탈출 가능한 최단 행동 순서 중 하나는 다음과 같다. `U`, `D`, `F`, `B`, `L`, `R`은 위·아래·앞·뒤·왼쪽·오른쪽 이동을 뜻한다. 이 표기는 해설용이며 입력으로 주어지지 않는다.

```text
BBBBRRFFRRBBRRBBLLUUUULLLLFFRRUUFFRRDDFFLLUURRRRDDBBUUBBDDLLDDLLLLFFUURRDDRRRRBBBBUUUUUBR
```

이 경로는 총 **89턴**이며, 층을 바꾸는 이동이 **27번** 포함된다. 실제로 1층부터 8층까지 모두 방문한다.

합법적인 행동을 턴 수가 적은 순서로 탐색했을 때 이보다 짧은 탈출 경로는 없으므로 출력은 89이다.
